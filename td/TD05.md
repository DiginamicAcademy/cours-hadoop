## **Introduction — le même geste, transféré**

Vous avez travaillé sur le Spotify depuis cinq jours : mapper, reducer, HDFS, Hive, HBase, NiFi. À chaque fois, la commande est la même — ce qui change, c'est la donnée. Le TP final utilise **un autre CSV** (`dataw_fro03_mini_1000.csv` — commandes d'articles). La structure est différente (`villecli`, `datcde`, `qte`, `libobj`…), mais le geste est identique.

Ce TD vérifie en 15 minutes que le mapper écrit dans `../annexes/utils/` fonctionne sur ce nouveau fichier — c'est la condition pour lancer le TP.

## **Tempo A — guidé : un mapper, deux sorties**

**1. Lancez le mapper sur le mini-jeu :**

```bash
cat data/dataw_fro03_mini_1000.csv | python3 annexes/utils/8-mapper-ventes.py | sort
```

**Ce que vous observez** : chaque ligne contient une **clé** (ville) et une **valeur** (nombre d'articles). Quelques villes apparaissent plusieurs fois : `LE MANS` apparaît avec la valeur `30`, `MAMERS` avec `18`, etc. Comparez au header : `villecli` est à la colonne 5, `qte` à la colonne 15 — le mapper extrait exactement ces deux champs.

**2. Pipez dans le reducer :**

```bash
cat data/dataw_fro03_mini_1000.csv | python3 annexes/utils/8-mapper-ventes.py | sort | python3 annexes/utils/2-structure-reducer.py
```

**Résultat attendu** : une seule ligne par ville, avec la somme des quantités. `LE MANS` = 30 articles, en tête.

**3. Même résultat, en SQL (sqlite3) :**

```bash
python3 - <<'EOF'
import csv, sqlite3, sys
conn = sqlite3.connect(':memory:')
c = conn.cursor()
c.execute('CREATE TABLE ventes (ville TEXT, qte INT)')
with open('data/dataw_fro03_mini_1000.csv') as f:
    r = csv.reader(f)
    next(r)  # sauter le header
    for row in r:
        if len(row) >= 16 and row[5]:
            try: c.execute('INSERT INTO ventes VALUES (?,?)', (row[5], int(row[15])))
            except ValueError: pass
conn.commit()
for v, total in c.execute('SELECT ville, SUM(qte) FROM ventes GROUP BY ville ORDER BY SUM(qte) DESC LIMIT 5'):
    print(f'{v}\t{total}')
EOF
```

Les 5 premières villes et les totaux sont **les mêmes** que dans le pipe. Le même résultat, deux chemins — c'est exactement la vérification que le TP vous demandera (Q1 MapReduce vs Q3 Hive).
